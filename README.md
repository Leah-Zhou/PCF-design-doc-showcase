# Design System Showcase

A public-safe design system documentation site for a product design portfolio.

Live site: [leah-zhou.github.io/design-system-showcase](https://leah-zhou.github.io/design-system-showcase/)

## Scope

- Foundations: Color, Typography
- Components: Button
- No private company patterns, proprietary tokens, internal product details, or confidential code.

## Run locally

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

This produces a static export in `out/`. GitHub Pages deploys that folder from the `main` branch.

## Stack

Next.js, React, TypeScript, CSS variables, and a Figma-backed token subset.
